# MITA Magazine — Premium Portfolio

Sito statico responsive pronto per GitHub Pages.

## Pubblicazione rapida
1. Carica tutti i file nella root del repository.
2. GitHub → Settings → Pages.
3. Source: Deploy from a branch.
4. Branch: main / root.
5. Save.

## Anteprima in Codespaces
Apri il terminale e lancia:

```bash
python3 -m http.server 8000
```

Poi apri la scheda PORTS e clicca il globo accanto alla porta 8000.

## Dove mettere foto, video e loghi
Leggi `ASSETS-GUIDE.md`.

## Testi da personalizzare
Apri `index.html` e cerca:
- hello@mitamagazine.com
- @mitamagazine
- statistiche `data-count`
- nomi di eventi e venue
- testi dei servizi

## Formati consigliati
- Foto hero/fullscreen: JPG o WebP, 2000–2600 px, sotto 700 KB.
- Portfolio: JPG o WebP, 1400–1800 px, sotto 450 KB.
- Video hero: MP4 H.264, 10–20 sec, senza audio, sotto 12 MB.
- Showreel: MP4 H.264, 45–90 sec, idealmente sotto 35 MB.
- Loghi: SVG trasparenti oppure PNG trasparenti.
