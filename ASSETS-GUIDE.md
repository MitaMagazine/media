## Come caricare in Codespaces
1. Nel pannello a sinistra, apri la cartella desiderata.
2. Tasto destro sulla cartella → Upload.
3. Seleziona il file dal computer.
4. Assicurati che il nome coincida esattamente.
5. Commit e Push.

Attenzione: GitHub distingue maiuscole e minuscole. `Hero.jpg` e `hero.jpg` sono file diversi.
